### 🌿 Sobre mim

Trabalho com ecologia, taxonomia e consultoria ambiental. Uso **R** e **Python** para organizar dados de campo, analisar distribuição de espécies e gerar relatórios.

### 🔬 Áreas de interesse

- Ecologia e taxonomia
- Levantamentos de fauna e dados de campo
- Distribuição de espécies e bases de biodiversidade (GBIF)
- Automação de relatórios ambientais
